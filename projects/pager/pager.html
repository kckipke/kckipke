Virtual memory pager simulator

C++
Operating systems
Virtual memory
Page replacement

This EECS 482 project implements a virtual memory pager — the layer between user processes and physical RAM. It manages page tables, physical memory frames, swap space, and file-backed mappings for multiple processes, handling page faults and evictions with a clock replacement algorithm.

Features:

  • Full pager API: vm_init, vm_create, vm_switch, vm_fault, vm_map, vm_destroy.
  • Clock algorithm page replacement with reference and dirty bit tracking.
  • Swap space management for anonymous (non-file-backed) pages.
  • File-backed page sharing across processes mapping the same file/block.
  • Process forking with arena duplication and a pinned zero page.
