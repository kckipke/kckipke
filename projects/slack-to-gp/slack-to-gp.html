Slack API

This CLI tool migrates photos and videos from a Slack channel into a Google Photos album. I built it for a student org where years of event photos lived in Slack and needed a permanent home in Google Photos.

How it works:

  • Fetches file URLs from a Slack channel using the Slack API (with pagination and rate-limit handling).
  • Downloads images and optionally videos from Slack-hosted links.
  • Authenticates with Google Photos via OAuth and uploads files into a named album.
  • Accepts channel ID, Slack token, Google auth file, and album name as CLI arguments.
