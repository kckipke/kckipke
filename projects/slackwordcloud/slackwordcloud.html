This project visualizes how my Slack workspace actually talks by turning channel message history into word clouds. It was built for a student org workspace to see which words dominate each channel's conversation.

Features:

  • Lists all channels the bot is a member of via the Slack conversations API.
  • Paginates through full message history for each channel, with rate-limit backoff.
  • Cleans message text (strips punctuation, lowercases) before aggregating word frequencies.
  • Generates a styled WordCloud image per channel, saved to a local clouds/ directory.
