Voter behavior via derandomized ballot data

Python
Election security
Data analysis
Research

This research project investigates the DVSorder vulnerability — a flaw in Dominion voting systems where ballot order can be inferred from cast-vote records. My work extended the upstream DVSorder tool with analysis scripts that cross-reference unshuffled ballot data with tabulator machine logs to reconstruct the exact order votes were cast.

Features:

  • Parsed Dominion cast-vote record (CVR) exports and ballot image archives.
  • Correlated DVSorder output with San Francisco 2020 and Alaska 2022 tabulator machine logs.
  • Handled multi-encoding log files (Windows-1252, MacRoman, chardet fallback).
  • Reconstructed vote order by matching ballot cast timestamps from scanner logs.
  • Produced structured JSON linking voter position, ballot ID, and cast time for behavioral analysis.
  • Final paper: "Voter Behavior via Derandomized Ballot Data" (EECS 498).
