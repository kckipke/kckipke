This EECS 482 project implements a network file server over TCP — clients send text protocol commands to create, delete, read, and write files and directories on a block-based on-disk filesystem. The server handles multiple concurrent clients with per-block read/write locks.

Features:

  • TCP server with a thread-per-connection model using Boost threads.
  • Block-based filesystem with inodes, directory entries, and free-block tracking.
  • CRUD operations: create/delete files and directories, read/write blocks.
  • Fine-grained concurrency via boost::shared_mutex per disk block plus a global mutex.
  • Request validation with Boost regex; handles deep paths, full disks, and concurrent clients.
