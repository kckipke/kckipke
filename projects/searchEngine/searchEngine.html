Distributed search engine

Python
Flask
MapReduce
PageRank
Multithreading

This EECS 485 project implements a miniature Google-style search engine end to end. A MapReduce pipeline crawls and indexes HTML documents, computes PageRank scores, and a distributed Flask server returns ranked results by fanning queries out to three index segment servers in parallel.

Features:

  • 6-job MapReduce pipeline: document count, HTML parsing, inverted index, and PageRank integration.
  • HTML parsing with BeautifulSoup; stopword filtering and term normalization.
  • TF-IDF + PageRank hybrid scoring with an adjustable weight parameter.
  • Distributed architecture: one search server + three index segment servers.
  • Parallel query fan-out via threading; returns top-10 ranked results.
