ScrappyAI (Winner Winner Chicken Dinner) is a conversational kitchen helper built for EECS 449. Users enter ingredients and preferences, and the chatbot generates complete recipes they can save, revisit, and ask follow-up questions about.

Features:

  • Multi-step chat flow: ingredients → generated recipe → save → optional image generation.
  • Recipe persistence with a saved-recipes page and delete support via SQLite.
  • Follow-up Q&A about generated recipes in conversational context.
  • Optional DALL-E 3 image generation only when the user requests it (saves compute).
  • User registration and login with Flask session-based auth.
  • "Make it special" modes for dietary tweaks like spicy, vegetarian, or kosher.
