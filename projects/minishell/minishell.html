This is my EECS 201 shell assignment — a from-scratch Unix shell that reads commands, manages processes, and handles built-in navigation. It was my first deep dive into how shells actually work under the hood.

Features:

  • Interactive REPL with a custom prompt showing USER:cwd$.
  • Built-in cd (with HOME fallback) and exit with optional exit code.
  • External command execution via fork, execvp, and waitpid.
  • EOF handling (Ctrl-D) and empty-input reprompting.
  • Graded via the EECS 201 GitLab autograder infrastructure.
