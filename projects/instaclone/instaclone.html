Insta485 is a team project from EECS 485 (Web Systems) — a full Instagram-style social network. I worked with Husain Saifuddin and Nathan Maloney to build the backend API, database schema, and frontend feed.

Features:

  • User auth: login, account creation, profile editing, password change, and account deletion.
  • Post feed from followed users with likes and threaded comments.
  • Explore page, user profiles, and followers/following lists.
  • REST API (/api/v1/) with session and HTTP Basic authentication.
  • Image uploads served from /uploads/; deployed to AWS.
